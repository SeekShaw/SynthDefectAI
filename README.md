# SynthDefect AI — 表面缺陷模拟生成工具

> 纯本地运行 · 无需联网 · 无需 GPU · 无需大模型 API

导入**产品照片**，自动识别定位产品
只在目标表面上模拟生成各类缺陷，并支持**明显/中等/不明显**分级，支持**划痕/凹坑/鼓包/异色/黑点/脏污/崩缺/异物**等缺陷
批量产出可用于检测模型训练的缺陷图与标注


## 核心特性

### 1. 区域约束
- 自动前景分割（Otsu + 连通域 + 背景甄别），横放/竖放/斜放通吃，**缺陷只会声称在产品轮廓范围内**
- 手动绘制区域：**缺陷位置画在哪，缺陷生成就在哪**，默认项

**产品轮廓可视化**（一眼看出缺陷会被限制在哪）
- 「显示产品轮廓」：用明显的线条描出识别到的产品边界，**颜色可用取色器修改**
- 「显示限定范围」：黄色虚线标出手绘限定范围
- 两者可独立开关；轮廓画在原图上，位于手绘图元之下，不影响绘制

#### 手绘区域（4 种画法）
- **手绘区域**（缺陷落点的控制方式）：
  | 画法 | 适用缺陷 | 说明 |
  |------|----------|------|
  | 画线条 | **仅划痕** | **按住左键拖一条线，松开即成一条划痕**（也可逐点点击，双击/右键/回车/「结束当前线条」结束）；**起止点与手绘一致** |
  | 画矩形区域 | 除划痕外 | 拖拽画框，**Ctrl+左键拖动**可旋转，也可用「ROI角度」输入 |
  | 画笔涂抹 | 除划痕外 | 按住左键自由涂抹 |
  - **绘制方式随启用的缺陷类型自动限制**：启用划痕 → 只能画线条（其它方式不可选）；
    启用其它类型 → 只能画矩形 / 画笔（「画多边形」已删除）
  - **区域归属当前缺陷页**：多类型缺陷同启时，在哪个缺陷页画的矩形/画笔就归哪个类型
  

### 2. 八类缺陷，位置受控
| 缺陷 | 仿真原理 | 位置约束方式 |
|------|---------|-------------|
| 划痕 | **拖拽式路径**（分段随机游走 + 偶发转折 + 低频蛇形 S 弯，移动平均平滑）+ 变宽度 + 微观抖动；**颜色白↔黑可调** | 方向**跟着生成区域走**（手绘 ROI 角度 / 笔迹主轴 / 表面长轴，整条路径主轴对齐，仅 ±10° 抖动），再掩膜裁剪 |
| 脏污 | 软边斑块场（径向 smoothstep 渐变）+ 分形噪声边缘 + 颗粒 + 飞溅点 + 按底色自动选污染色 | 斑块中心**主动避开区域边界**（`_fit_blob_in_region`）+ 区域**向内羽化**，不会被直边切出硬痕 |
| 异色 | Lab 色域偏移（泛黄/蓝/绿/红/紫/褪色/自定义取色）+ 软边不规则区域 + 低频不均匀 | 同脏污：中心避边界 + 区域羽化 |
| 崩缺 | **沿产品边沿**的月牙状浅缺口：切向跨度 × 内法线浅深度，深度受**局部半厚度**约束；多频角向抖动成崩口锯齿 + 断面颗粒 + 交界暗边 + 崩渣 + 发丝裂纹；**边界柔和度**控制断口过渡带宽（实测 3→7.5px），**颜色接近度**让断面颜色趋近邻近区域（实测色差 9.2→1.0） | 断面必须紧贴产品轮廓内侧（实测最小距离 1px） |
| 黑点 | 深色针孔/黑斑：**不规则的圆/椭圆**（长宽比、朝向随机）+ 软边场平滑衰减（**边界柔和度**可调）+ **颜色可自定义取色**（颜色深度=不透明度，调到 1 中心即纯色）+ **支持成簇出现**；手绘区域只限定范围、不改形状 | 中心在目标表面内采样 + 区域向内羽化（无直边切痕） |
| 凹坑 | 麻点/缩孔：**负球冠高度场求法线 → Lambert 方向性明暗**（光源侧内壁暗、对侧亮弧——「凹」的正确极性），高度场保持光滑以避免漩涡伪影，噪声只作用于坑口轮廓 | 中心在目标表面内采样 + 掩膜裁剪 |
| 异物 | 贴附颗粒/纤维/金属屑：独立颜色 + **投影**（光照反方向偏移模糊，贴附感关键）+ 轻微厚度明暗 + 纤维状两端渐细 | 中心在目标表面内采样 + 掩膜裁剪 |
| 鼓包 | 表层局部隆起/起泡：**正球冠高度场（凸的明暗极性，与凹坑相反）**，auto 模式**保留原表面材质**只叠加明暗（颜色天然与邻近区域一致），custom 模式可自定义取色；边缘经软过渡融入周围（**边缘过渡**可调），顶部柔和高光 | 中心在目标表面内采样 + 掩膜裁剪 |


**缺陷生成数量**：**默认全部为 1，上限 5**
- **数量也是绘制上限**：原图中允许画的线条 / 区域个数 = 对应缺陷的生成数量
- **每实例单独调整**：数量 ≥2 时「明显度」右侧出现「**调整第几处**」下拉

### 3. 明显度分级（困难样本）
| 等级 | 参数缩放 | 用途 |
|------|---------|------|
| 明显 obvious | 0.8~1.0 | 强正样本 |
| 中等 medium | 0.45~0.7 | 常规样本 |
| 不明显 subtle | 0.12~0.35，边缘更柔 | 接近检测阈值的困难负样本 |
| 随机混合 mixed | 0.12~1.0 | 一次生成全谱系 |


## 输出产物

```
输出目录/
├─ images/                 缺陷图（训练输入）
├─ masks/<类型>/           各类型缺陷掩膜（灰度 PNG，白=缺陷）
├─ region/                 分割可视化 overlay + 区域图 map（127=瓷体 255=电极）
├─ previews/<类型>/        原图｜区域与缺陷叠加｜缺陷图 三联对比
├─ labels/                 YOLO txt
├─ annotations_voc/        Pascal VOC xml（含 surface 字段）
├─ annotations_coco.json   COCO json（含 surface 字段）
└─ dataset_info.json       全部参数与统计
```

## 使用

### 图形界面
双击 `SynthDefectAI.exe`（或 `python app.py`）：
1. 顶部「1 · 输入设置」选择 产品图片 / 文件夹 —— 自动完成区域检测，
2. 顶部「2 · 缺陷图生成配置」中切换 Tab（划痕 / 脏污 / 异色 / 崩缺 / 黑点 / 凹坑 / 异物 / 鼓包），
   勾选 **Tab 标签上的复选框** 启用该缺陷
3. 需要限定局部时：勾选「限定手绘区域」→ 预览左栏画矩形或涂抹
4. 需要限定落点时：勾选「限定手绘区域」，按缺陷类型选画法
5. 输入设置卡片用「◀ 上一张 / 下一张 ▶」逐张查看
6. 设置每图张数、随机种子、输出目录：
   - 点底部「**保存缺陷图**」把**当前这张预览**的缺陷图存到输出目录
   - 点「**批量生成全部**」对已导入的所有图片批量生成
7. 预览支持滚轮缩放（光标锚点）、拖拽平移、双击适应窗口，三栏同步

### 命令行
```bash
# 瓷体脏污 + 不明显划痕（困难样本）
SynthDefectAI.exe --cli -i mlcc图片夹 -o out --kinds scratch,smudge --severity subtle

# 黑色划痕 + 更弯的路径（--scratch-tone -1~1：-1 白 … +1 黑；0 随机）
SynthDefectAI.exe --cli -i 图片夹 -o out --kinds scratch --scratch-tone 1.0 --scratch-tone-depth 1.2
SynthDefectAI.exe --cli -i 图片夹 -o out --kinds scratch --scratch-tone -1.0 --scratch-curve 0.8
```

## 使用建议
- 拍摄建议：产品充满画面、背景与产品对比清晰；背景可选「自动判别」
- 分割不准时：使用手绘区域方式来限定缺陷生成位置
- 手绘区域仅对当前选中的那一张图片生效
- 检测任务建议 `mixed` 明显度 + 多种子，覆盖困难样本谱系
- 分类任务建议按表面×缺陷类型单独出批（`--kinds` + `--target`）

```bash

python tools/smoke_gui.py       # GUI 离屏冒烟测试（150+ 项断言，含布局不重叠/不裁切回归）

python tools/verify_region.py   # 分割 IoU + 越界率矩阵 + 明显度差异
python tools/test_chip.py       # 崩缺缺陷专项（越界 / 目标表面 / 明显度）

```
