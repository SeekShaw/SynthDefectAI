# SynthDefect AI — MLCC 表面缺陷合成工具

导入**合格的 MLCC 产品照片**，自动分割出**瓷体**与**端电极**表面，
只在目标表面上合成**划痕 / 脏污 / 异色**缺陷，并支持**明显 / 中等 / 不明显**分级，
批量产出可用于检测模型训练的缺陷图与标注。

> 纯本地运行 · 无需联网 · 无需 GPU · 无需大模型 API

## 核心特性

### 1. 区域约束（缺陷只落在产品表面）
- 自动前景分割（Otsu + 连通域 + 环形背景甄别），横放/竖放/斜放通吃（PCA 主轴）
- **轴向颜色剖面法**自动检测端电极宽度：两端电极与瓷体色差剖面 → Otsu 自适应阈值
- 手动兜底：电极宽度占比可手动指定（0.03~0.45）；背景亮度先验可选（深色/亮色背景）

#### 缺陷位置方式（二选一）
工具条第二行「缺陷位置」可切换缺陷落点的依据：

| 方式 | 缺陷生成范围 | 何时用 |
|------|--------------|--------|
| **限定在产品轮廓内** | 产品表面 **∩** 手绘区域 | 产品识别准确时使用，缺陷绝不越出产品 |
| **按图像坐标位置** | **就是**手绘区域的像素坐标 | 产品识别不准/识别不到时使用；**识别对错都不影响落点** |

> 「按图像坐标位置」下产品轮廓仍会画出（供对照参考），但**不参与**缺陷位置计算。
> 手绘区没画到产品上时，前者会明确提示并建议改用后者，不会把缺陷洒满整图。

**产品轮廓可视化**（一眼看出缺陷会被限制在哪）
- 「显示产品轮廓」：用明显的线条描出识别到的产品边界，**颜色可用取色器修改**、线宽 1~8px
- 「显示限定范围」：黄色虚线标出手绘限定范围
- 两者可独立开关；轮廓画在原图上，位于手绘图元之下，不影响绘制

#### 手绘区域（4 种画法）
- **手绘区域**（缺陷落点的控制方式）：
  | 画法 | 适用缺陷 | 说明 |
  |------|----------|------|
  | 画线条 | **仅划痕** | **按住左键拖一条线，松开即成一条划痕**（也可逐点点击，双击/右键/回车/「结束当前线条」结束）；**起止点与手绘一致** |
  | 画矩形区域 | 脏污 / 异色 / 缺角 | 拖拽画框，**Ctrl+左键拖动**可旋转，也可用「ROI角度」输入 |
  | 画多边形 | 脏污 / 异色 / 缺角 | 逐点点击，点回起点或双击/右键/回车闭合 |
  | 画笔涂抹 | 脏污 / 异色 / 缺角 | 按住左键自由涂抹 |
  - 线条**不会**被当成脏污/异色/缺角的区域
  - **「限定手绘区域」默认开启**；画笔滑条只在「画笔涂抹」模式下出现
  - 没画完的线条/多边形，点「刷新预览」或切换绘制模式时会**自动提交**，不会丢失
- 分割产物：`region/` 目录下每图分割可视化 + 区域图（127=瓷体 255=电极）

实测（5 样例 × 3 目标表面 × 4 明显度 × 6 种子，共 360 组）：
分割产品 IoU = 1.000，缺陷越界率全部为 **0.00%**。

### 2. 四类缺陷，位置受控
| 缺陷 | 仿真原理 | 位置约束方式 |
|------|---------|-------------|
| 划痕 | **拖拽式路径**（分段随机游走 + 偶发转折 + 低频蛇形 S 弯，移动平均平滑）+ 变宽度 + 微观抖动；**颜色白↔黑可调** | 方向**跟着生成区域走**（手绘 ROI 角度 / 笔迹主轴 / 表面长轴，整条路径主轴对齐，仅 ±10° 抖动），再掩膜裁剪 |
| 脏污 | 分形噪声斑块 + 颗粒 + 飞溅点 + 按底色自动选污染色 + **高斯柔边** | 斑块中心在目标表面内采样 + 掩膜裁剪 |
| 异色 | Lab 色域偏移（泛黄/蓝/绿/红/紫/褪色）+ 不规则边界 + **高斯柔边** | 区域中心在目标表面内采样 + 掩膜裁剪 |
| 缺角 | 角点半平面断面 + 多频角向抖动 + 分形贝壳纹 + 颗粒断面 + 碎屑/裂纹 | 断面必须落在产品轮廓内侧 |

每类缺陷可独立指定目标表面：**瓷体 / 端电极 / 瓷体+端电极**。

**数量参数即最终个数**：划痕条数 / 脏污斑块数 / 异色区域数 / 缺角个数默认都是 **1**，
且不再随强度浮动（不会出现「设 1 却出 3 条」）。强度只影响宽度、长度、透明度等物理量。

**划痕跟随手绘线条**：勾选「限定手绘区域」→ 选「画线条」→ **按住左键拖一条线**（松开即成线），
划痕就沿这条线生成，**起止位置与手绘一致**（实测拖动起止点与线条端点偏差0.8 / 2.0 px）；
画 N 条线就生成 N 条，「条数」表示每条线再生成几条平行划痕。
没画线时预览会提示「划痕待画线」，**第三栏仍显示原图而不是空白**；批量流程无手绘，按下面的规则自动生成。

**未画线时（批量流程）划痕方向跟着「生成区域」走**：不再随机。
- 画了 ROI 矩形 → 取矩形的角度；画笔涂抹 → 取笔迹主轴；没手绘 → 取目标表面（瓷体/端电极）长轴。
- 实现上把整条路径绕起点**旋转到目标方向**（随机游走只负责形状），
  再叠加 ±10° 的自然抖动，因此多条划痕互相平行、整体朝向可控。
- 实测：ROI 0°/30°/60°/90° 时逐条主轴平均偏差 1.3° / 13.7° / 6.5° / 9.3°。

**划痕颜色白↔黑可调**：
- 「颜色」滑条 -1 = 白 … +1 = 黑，0 = 按凹陷暗线/亮反光线随机（保持真实划痕的随机性）；
- 「深浅」滑条 0.1~1.5 控制偏离原色的程度（实测：白 +14 → +73，黑 -17 → -87）；
- 明确指定颜色后，强度滑条不再二次放大颜色，避免过曝。

**划痕路径本身是蜿蜒的**：把长度切成若干段，每段方向做随机游走（模拟手抖），
以一定概率来一个明显转折，再叠加 1~4 个周期的低频蛇形 S 弯，最后移动平均平滑。
滑条「弯曲度」0 = 近直线，1 = 明显蜿蜒，默认 0.55。

**脏污 / 异色边缘柔和**：覆盖率阈值化前先补一次高斯模糊（σ = 斑块半径 × 系数），
掩膜与合成图都是渐变过渡，没有硬边；飞溅小点也一并轻糊。
滑条「边缘模糊」0~2.5，默认 1.0（脏污 edge_soft / 异色 edge_blur）。
> 注意顺序：**先模糊 → 再按覆盖率阈值 → 最后裁到产品表面**。
> 若把模糊放在阈值之后，软晕会反过来把「明显 / 不明显」的面积差异冲淡（实测比值从 2.0x 掉到 1.3x）。
> 异色区尺寸以**产品外接框短边**为基准（与缺角同一口径），避免斑块吞掉整个产品导致面积对明显度不敏感。

### 3. 明显度分级（困难样本）
| 等级 | 参数缩放 | 用途 |
|------|---------|------|
| 明显 obvious | 0.8~1.0 | 强正样本 |
| 中等 medium | 0.45~0.7 | 常规样本 |
| 不明显 subtle | 0.12~0.35，边缘更柔 | 接近检测阈值的困难负样本 |
| 随机混合 mixed | 0.12~1.0 | 一次生成全谱系 |

## 图形界面

```
┌──────────────┬───────────────────────────────┬────────────────┐
│ 1 · 输入设置 │ 2 · 缺陷图生成配置            │ 3 · 输出设置   │
│ 选择图片/目录│ 划痕（当前缺陷名随 Tab 切换） │ 输出目录       │
│ 图片列表     │ [○划痕][○脏污][○异色][○缺角] │ 每图张数/种子  │
├──────────────┴───────────────────────────────┴────────────────┤
│ ① 图像操作：限定手绘区域 / 线条·矩形·多边形·画笔 / ROI角度 │
│ ② ROI角度(+-90°) + 缩放 │ ③ 状态信息：缺陷/占比/越界/方向/seed │
│ 原图·手绘 │ 区域与缺陷 │ 缺陷图   三栏同步缩放             │
├───────────────────────────────────────────────────────────────┤
│ 进度条 · 刷新预览 · 开始批量生成 · 停止                        │
└───────────────────────────────────────────────────────────────┘
```
- **上半部分三张卡片等高**（输入设置 / 缺陷图生成配置 / 输出设置），
  高度按内容最小需求统一，卡片之间不会与下方预览交叠
- **四类缺陷**：划痕 / 脏污 / 异色 / 缺角，卡片顶部就是这四个名字的 **Tab 分页**
  （● 已启用 / ○ 未启用），每页内只有「启用」复选框 + 明显度 + 各项参数
  （**不再有「目标表面」选择**，缺陷统一落在产品可见表面上）
  - **划痕默认开启**，脏污 / 异色 / 缺角默认关闭（需勾选各页内「启用『XX』缺陷」）
- **输出设置默认只有「缺陷图」勾选**，掩膜 / 对比图 / 区域分割图 / 三种标注文件默认全部关闭
- **参数行自适应 1 / 2 列**：窗口宽时两列排布把卡片压到最矮，窄时回落单列，
  文字始终完整显示；窗口最小尺寸 1180×720（再小会互相遮挡，故不再允许缩小）
- **工具条三行**（窄窗口下控件不会被挤扁、文字始终完整）：
  ① 手绘（限定手绘区域 / **画线条·画矩形·画多边形·画笔** / 与产品求交 / 清除手绘 / 结束当前线条）
  ② **ROI角度 / ＋90° / －90°**（仅矩形模式显示）+ 缩放（－ / 1:1 / 适应窗口 / ＋）
  ③ 状态信息（缺陷类型 / 占比 / 越界率 / 划痕方向 / seed）
- **可旋转 ROI**：矩形 ROI 可**按住 Ctrl 左键拖动**旋转，也可用「ROI角度」精确输入；
  掩膜按旋转矩形栅格化，缺陷只落在斜框内
- **三栏预览**：滚轮缩放（光标锚点）、拖拽平移、双击适应窗口，三栏同步
- **越界自检**：工具条实时显示「缺陷类型 / 缺陷占比 / 越界率 / 划痕方向 / seed」
- 产品区域检测内置常开（不再单独显示），无运行日志块，提示走底部状态栏

## 使用

### 图形界面
双击 `SynthDefectAI.exe`（或 `python app.py`）：
1. 顶部「1 · 输入设置」选择 MLCC 产品图片 / 文件夹 —— 自动完成区域检测，
   预览中间栏实时显示瓷体（绿）/电极（蓝）分割
2. 顶部「2 · 缺陷图生成配置」中切换 Tab（划痕 / 脏污 / 异色 / 缺角），
   勾选页面内的「启用『XX』缺陷」**（四种默认全部关闭）**，再调目标表面、明显度、强度、数量
3. 需要限定局部时：勾选「限定手绘区域」→ 预览左栏画矩形或涂抹
4. 需要限定落点时：勾选「限定手绘区域」，按缺陷类型选画法
   - 划痕 → 「画线条」：**按住左键拖一条线**（松开即成线，起止点即划痕起止点）；
   - 脏污 / 异色 / 缺角 → 「画矩形区域」（Ctrl+拖动可旋转）、「画多边形」或「画笔涂抹」。
5. 输入设置卡片用「◀ 上一张 / 下一张 ▶」逐张查看
6. 设置每图张数、随机种子、输出目录：
   - 点底部「**保存缺陷图**」把**当前这张预览**的缺陷图存到输出目录
     （文件名形如 `mlcc_h_std_scratch_seed42.png`，可选同时存掩膜/对比图）
   - 点「**批量生成全部**」对已导入的所有图片批量生成
7. 预览支持滚轮缩放（光标锚点）、拖拽平移、双击适应窗口，三栏同步

### 命令行
```bash
# 瓷体脏污 + 不明显划痕（困难样本）
SynthDefectAI.exe --cli -i mlcc图片夹 -o out --kinds scratch,smudge --severity subtle

# 黑色划痕 + 更弯的路径（--scratch-tone -1~1：-1 白 … +1 黑；0 随机）
SynthDefectAI.exe --cli -i 图片夹 -o out --kinds scratch --scratch-tone 1.0 --scratch-tone-depth 1.2
SynthDefectAI.exe --cli -i 图片夹 -o out --kinds scratch --scratch-tone -1.0 --scratch-curve 0.8
```

# 只在端电极上生成明显划痕
SynthDefectAI.exe --cli -i in -o out --kinds scratch --target electrode --severity obvious

# 深色背景产品 + 手动指定电极宽度 18%
SynthDefectAI.exe --cli -i in -o out --bg-side bright_fg --electrode-ratio 0.18
```

## 使用建议
- 拍摄建议：产品充满画面、背景与产品对比清晰；背景可选「自动判别」
- 分割不准时：先切换「背景亮度」选项，再手动指定「电极宽度」
- 手绘区域仅对当前选中的那一张图片生效
- 检测任务建议 `mixed` 明显度 + 多种子，覆盖困难样本谱系
- 分类任务建议按表面×缺陷类型单独出批（`--kinds` + `--target`）
